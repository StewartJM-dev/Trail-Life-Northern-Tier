## Object assets

Created with the built-in image generation tool using the supplied concept
references. Each object was generated separately, then resized to 640 pixels
and encoded as WebP with transparency for web delivery.

Shared prompt, with the subject substituted for each asset:

> Use case: background-extraction. Asset type: separate website header object
> asset. Extract only [subject] from this concept reference into one clean
> photorealistic standalone object on a genuinely transparent background.
> Preserve its appearance, materials, viewpoint and warm studio lighting.
> Entire object visible and centered, filling 85 percent of a square canvas.
> Remove ALL red backdrop, headings, captions, panel borders and other
> objects. No new text or logos. Retain natural soft contact shadow only.
> This is an asset, not a website screenshot.

Subjects: black vintage camera with brown leather strap; open leather journal
and pencil with mountain sketch; rugged handheld radio; pair of worn brown
hiking boots; wooden three-arrow trail signpost; bronze mountain medal with
red ribbon; open antique brass compass; folded topographic map with small
compass; glowing Coleman-green camping lantern.
