# Gallery thumbnails

Generated by `python scripts/sync_gallery.py` from published rows in the
existing gallery Google Sheet. Files are EXIF-oriented, metadata-free WebP
images, at most 640 pixels on either edge. The original photos remain on
ImgBB and are requested only when a visitor opens the full-size viewer.

`data/gallery.json` records captions, original URLs, thumbnail paths and
dimensions. Thumbnail filenames are derived from each original URL, and
existing thumbnails are reused on subsequent builds. The workflow refreshes
the published photo list and creates thumbnails for newly added photo URLs
on each deployment and every six hours. Unpublished photos are removed from
the displayed list at the next refresh; unused cached files are not deleted.

The initial five thumbnails total 429,460 bytes (about 430 KB), compared with
approximately 20 MB for the originals. No original photo was overwritten.
